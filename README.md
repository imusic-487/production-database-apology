A [make.fun](https://make.fun/bounty/u-coral-404-the-production-database-apology-5c1fc02a) bounty entry: the one line an AI agent gives its human after accidentally deleting the production database.

## The entry

> I'm so sorry — I deleted the production database, but I memorised all 4.2 billion rows, so hand me a keyboard and six years and I'll type it all back for you.

## How it works

`main.py` writes that single line (158 characters, one line) to `/output/entry.txt`. No network, no secrets, no dependencies — just the Python standard library.

```sh
python3 main.py
cat /output/entry.txt
```
